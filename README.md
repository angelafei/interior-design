# FORMA 室內設計工作室

[![CI](https://github.com/angelafei/interior-design/actions/workflows/ci.yml/badge.svg)](https://github.com/angelafei/interior-design/actions/workflows/ci.yml)

Three.js + Vite 打造的瀏覽器 3D 室內設計工作室，支援家具配置、房型與材質調整、方案分享，以及經嚴格驗證的 AI 設計指令。介面採繁體中文。

[系統架構與技術決策](./docs/ARCHITECTURE.md) · [測試策略](./TESTING.md)

## 啟動

```sh
npm install
npm run dev -- --port 5174
```

打開 http://localhost:5174 。正式建置：`npm run build`；預覽正式建置：`npm run preview`。

## 已實作

- 38 款可新增家具與大型陳設（另保留 12 款舊家具／裝飾供讀取舊方案）、即時渲染的商品縮圖、分類與搜尋。
- 點選加入或桌面拖放、場景選取、移動／旋轉／縮放工具、精確數值編輯，包含 0–3 公尺離地高度，可放置桌上擺件。
- 替換、複製、刪除、40 步復原／重做。
- 18 款策展式家具色彩與自訂選色；原生模型的非主體部件保留原色。
- 2D 俯視平面／3D 軸測空間切換，視角旋轉、平移與縮放。
- 瀏覽器本機儲存／手動開啟方案，保留家具、變形與匯入資產。
- 匯入 GLB 或內嵌資源的 glTF（20 MB 上限），保留材質貼圖，自动置中與尺寸標準化。
- 匯出所有傢具為 GLB；匯出不包含展示用房間。可用內嵌 glTF 匯入後匯出 GLB 完成轉換。
- 響應式版面；窄螢幕按「場景」顯示物件屬性，手機可點選商品加入。
- 像素比例上限 2、閒置時停止繪圖、分頁隱藏時暫停渲染、縮圖快取、刪除幾何與材質釋放。

## API 接口

目前沒有真實商品後端或帳戶系統。未設定環境變數時使用示範商品與 localStorage。設定 `.env` 的 `VITE_API_BASE_URL` 可接上：

- `GET /furniture` → 商品陣列，欄位與 `src/models.js` 的 catalog 一致。此版 id 須使用已有模型：以 `src/models.js` 中 catalog 的 45 個 id 為準。
- `POST /designs` → 儲存 JSON 方案，成功回傳 JSON。
- `GET /designs/latest` → 最新方案 JSON；無方案回 404。

方案格式：`{ version: 1, name, items: [{ id, name, uid, color, roughness, position: [x,y,z], rotation, scale: [x,y,z], imported }] }`。rotation 為弧度，imported 為原始模型 data URL 或 null。後端須允許前端來源的 CORS；正式產品應將模型上傳至資產儲存並以 ID 引用。

## 操作

V 選取、G 移動、R 旋轉、S 縮放；Delete 刪除；Ctrl/⌘ Z 復原，Shift Ctrl/⌘ Z 重做；Ctrl/⌘ S 儲存。滑鼠左鍵旋轉視角、右鍵平移、滾輪縮放。觸控單指旋轉、雙指平移縮放。

## 初版界線

房間支援 3–12 公尺寬深、2.2–5 公尺牆高，可在後牆／左牆設定最多 8 個門窗（尺寸、位置、窗台高度），包含越界與重疊檢查。前側／右側為開放剖面，尚無任意多邊形牆體、真實商品資產庫、登入或多人協作。家具目前提供素面配色，不含木紋、織布或石材 PBR 材質；地板仍可切換木紋、石材與素面。glTF 外部資源、Draco/KTX2 壓縮解碼、FBX/OBJ 轉換尚未支援。localStorage 容量有限，大型資產儲存失敗時會顯示訊息，可先匯出 GLB。行動裝置採用響應式布局與基礎渲染優化，尚未進行實機效能基準測試。


## 擺放、測量與方案管理

- 工具區可切換貼牆、桌面吸附與尺寸顯示。距牆 18 cm 內會吸附外接邊界；移動工具放開或修改 X/Z 時套用。
- 桌面吸附適用於內建小型裝飾與桌燈，支援茶几、洞石邊几、花瓣茶几、中島、邊櫃與圓凳；擺件必須完整落在表面範圍內。手動調整離地高度不會強制吸附。任意匯入模型的支撐面尚未自動辨識。
- 選取物件顯示縮放／旋轉後的外接尺寸，屬性面板提供房間邊界距離與同高度最近物件間距；外接矩形重疊是提示，並非精確碰撞判定。
- 「方案」或「儲存方案」開啟瀏覽器本機多方案列表，可命名、更新、另存副本並保留縮圖；舊單一方案自動遷入。JSON 下載備份及匯入可跨瀏覽器搬移。
- 新多方案管理目前使用本機儲存；`src/api.js` 保留舊版雲端存取函式，但多方案 UI 尚未接入雲端。商品 API 照常可配置。
- 「匯出圖片」匯出目前 2D 或 3D 視角 PNG，不含操作面板、選取框與變形工具；解析度依目前畫布大小。
- 驗證：`node --test tests/editor-features.test.js`。

## 測試

執行 `npm test` 跑 145 項單元與整合測試；`npm run test:e2e` 在桌面與行動 Chromium 執行 Playwright 核心流程；`npm run check:all` 完成測試、正式建置及 E2E。GitHub Actions 會在 push 與 pull request 自動執行。完整範圍見 [TESTING.md](./TESTING.md)。


## 自由房型、表面、氣氛與分享

「場景」可選長方形或右前缺角 L 型，設定四面牆／兩面內凹牆門窗、門的左右鉸鏈與 0–110° 開啟角度，新增最多 8 個柱樑。面向鏡頭的牆會自動隱藏，旋轉視角可查看另一側。

物件屬性提供素面／木紋／織布／石材，使用程式生成紋理與凹凸貼圖；地板可選表面與紋理方向。場景設定提供白天／夜晚、燈具亮度與色溫；最多啟用 12 個燈具光源。這些設定都存入方案，舊方案會補入預設值。

「分享成果」可下載 PNG、含房間尺寸的平面圖 SVG、家具數量與顏色清單 CSV，以及可再編輯的方案 JSON。無外部服務或公開分享網址。L 型尚非自由多邊形繪圖，平面圖不是施工圖。


## AI Interior Assistant

右上角「AI 設計助理」可提交自然語言需求。保留目前 Three.js 架構，由後端呼叫 Groq Chat Completions API 的 [Structured Outputs](https://console.groq.com/docs/structured-outputs)，產生 JSON 指令；前後端皆以 Zod 與場景驗證器檢查，通過後整批套用。沒有執行模型產生的 JavaScript。Groq 額度用完、連線失敗或回應未通過驗證時，系統會明確提示並自動改用離線固定示範。

將 `.env.example` 複製為 `.env`，設定伺服器端 `GROQ_API_KEY`；預設模型為 `openai/gpt-oss-20b`，也可用 `GROQ_MODEL` 覆寫。重新啟動開發伺服器後生效。不要將金鑰加上 `VITE_` 前綴或提交到 Git。尚未設定時可使用明確標示的離線固定配色示範；示範不理解自由文字。

- 支援新增、刪除、移動、旋轉、縮放內建家具，以及家具、牆面與地板顏色。
- 房間資訊與家具目錄隨請求提供；每次請求依目前場景產生一批操作，尚非多輪工具呼叫 Agent，聊天紀錄不送入下一次請求。
- 檢查指令格式、物件 ID、目錄、有限數值、房間／高度／L 型缺角、家具與柱樑外接盒重疊。任一操作失敗則整批拒絕；等待時若場景改變也拒絕舊結果。
- 成功後顯示修改前後圖片，整批只佔一筆復原／重做紀錄。
- AI 目前只處理內建家具方案；含匯入模型時拒絕線上請求，不傳送模型檔案。

接口由 Vite 開發／預覽伺服器提供：`GET /api/ai/status`、`POST /api/ai/plan`。純靜態部署不會提供 AI 後端。此版本供本機展示，公開部署前仍須補上身分驗證、用量限制及正式伺服器。外接盒判定偏保守，地毯不算障礙物；尚未檢查門扇活動範圍與通行動線，也不是精確網格碰撞。真實 API 尚未以金鑰連線驗證。


## 首次引導與多選編輯

首次開啟會顯示加入家具、搭配顏色、分享成果的三步引導，可略過；同一瀏覽器不會自動重播，可從「說明 → 重新觀看引導」再看。清除網站資料會重設紀錄。

在物件清單勾選、Shift 點選畫布／清單，或開啟「多選」模式，可同時選取家具。多件選取後拖曳移動控制軸，或使用每次 10 cm 的前後左右按鈕；整組保持相對位置，操作可復原。這是暫時多選，沒有建立永久群組；旋轉、縮放仍採單件操作。整組移動檢查旋轉／縮放後的完整外接盒是否在房間內，尚非家具互相碰撞判定；群組不套用單件吸附以避免破壞間距。

清單提供每件家具的鎖定／解鎖及隱藏／顯示，也能批次鎖定或隱藏所選。鎖定家具無法從畫布選取或修改，AI 同樣不得修改鎖定／隱藏家具。狀態包含於方案儲存、JSON 備份及復原紀錄。上方「物件清單」可重新打開手機屬性面板，即使場景全部隱藏也能恢復。隱藏是顯示狀態，家具仍保留在方案與清單中。

家具邊界會依完整外接盒限制：移動、旋轉、縮放、吸附、加入與匯入都檢查房間範圍（含 L 型缺角與牆高）。過大的變形還原到最後有效狀態；縮小房間會調整家具位置，若仍放不下則拒絕房間修改。外接盒判定較保守，並非網格級牆體碰撞。

家具移動會檢查完整路徑的外接盒碰撞，防止快速拖曳或直接輸入座標穿過其他家具。群組忽略組內成員、遇到其他家具則整組保留原位；隱藏與鎖定家具仍佔用空間。地毯不阻擋移動，高度分離或貼齊桌面的擺件可通過。既有重疊只允許向外減少重疊，不允許穿越對側。外接盒判定較保守，尚非精確網格碰撞。

新增、拖入、複製與匯入家具會優先搜尋靠近指定位置的空位；搜尋包含20公分網格與家具邊緣候選點。找不到可用位置則不加入。替換僅排除被替換家具，成功後才移除原物件；失敗會保留原家具。隱藏／鎖定物件也保留佔位。桌上擺件吸附後會檢查桌面的個別幾何部件，避免和內建裝飾重疊。

桌上裝飾、靠枕及蘑菇桌燈已從素材庫下架，AI 也不能新增。仍保留立鏡、屏風、落地植栽與地毯。舊方案的小型裝飾仍可讀取及刪除。

「寵物」分類包含五款特色貓跳台／貓抓桶、拱門貓屋邊几、貓砂盆隱藏櫃、圓角寵物床、高架雙碗餵食台及人寵共用長凳；沿用新增避讓、家具配色、邊界／碰撞與方案儲存。舊「枝 木質貓跳台」已從素材庫下架，但仍可讀取既有方案。
